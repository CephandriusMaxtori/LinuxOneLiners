🐧 Linux Utility One-Liners

Quick maintenance, cleanup, and automation scripts for Linux & Raspberry Pi.

⚡ System Update & Reboot

Updates package lists, performs distribution upgrades, removes unused dependencies, clears cache, and reboots safely after a 5-second delay.

curl -fsSL https://cephandriusmaxtori.github.io/LinuxOneLiners/update.sh | sudo bash

🐳 Docker Container Updater

Pulls updated image tags for Docker Compose stacks, restarts updated containers, and prunes unused dangling images to free up storage.

curl -fsSL https://cephandriusmaxtori.github.io/LinuxOneLiners/docker-update.sh | bash

🧹 System & Log Cleanup

Vacuums systemd journalctl logs older than 3 days, wipes temp/thumbnail caches, and truncates large system log files to preserve space.

curl -fsSL https://cephandriusmaxtori.github.io/LinuxOneLiners/system-clean.sh | sudo bash
